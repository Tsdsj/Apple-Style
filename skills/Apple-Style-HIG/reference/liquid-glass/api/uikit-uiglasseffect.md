# UIGlassEffect

A visual effect that renders a glass material.

## Initializers

- [init(style:)](https://developer.apple.com/documentation/uikit/uiglasseffect/init(style:)) — Creates a glass effect with the specified style.

## Instance Properties

- [isInteractive](https://developer.apple.com/documentation/uikit/uiglasseffect/isinteractive) — Enables interactive behavior for the glass effect.
- [tintColor](https://developer.apple.com/documentation/uikit/uiglasseffect/tintcolor) — A tint color applied to the glass.

## Enumerations

- [UIGlassEffect.Style](https://developer.apple.com/documentation/uikit/uiglasseffect/style)
