# NSGlassEffectView

A view that embeds its content view in a dynamic glass effect.

## Instance Properties

- [contentView](https://developer.apple.com/documentation/appkit/nsglasseffectview/contentview) — The view to embed in glass.
- [cornerRadius](https://developer.apple.com/documentation/appkit/nsglasseffectview/cornerradius) — The amount of curvature for all corners of the glass.
- [effectIsInteractive](https://developer.apple.com/documentation/appkit/nsglasseffectview/effectisinteractive) — Enables interactive glass behavior, which adds a visual response to user interactions.
- [style](https://developer.apple.com/documentation/appkit/nsglasseffectview/style-swift.property) — The style of glass this view uses.
- [tintColor](https://developer.apple.com/documentation/appkit/nsglasseffectview/tintcolor) — The color the glass effect view uses to tint the background and glass effect toward.
