# GlassProminentButtonStyle

A button style that applies prominent glass border artwork based on the button’s context.

## Overview

You can also use [glassProminent](https://developer.apple.com/documentation/swiftui/primitivebuttonstyle/glassprominent) to construct this style.

## Initializers

- [init()](https://developer.apple.com/documentation/swiftui/glassprominentbuttonstyle/init()) — Creates a prominent glass button style.

## Instance Methods

- [makeBody(configuration:)](https://developer.apple.com/documentation/swiftui/glassprominentbuttonstyle/makebody(configuration:)) — Creates a view that represents the body of a button.
