Write the decision, not only the task

A task says what to do. Six weeks later, nobody remembers why the task was chosen over the other options. A decision record keeps that answer.

Four lines are enough

Write the decision, the date, the owner and the options that were set aside. Four lines take a minute and save an afternoon of argument later.

We chose shared boards for every plan, because the team asked for them first. We set aside per-board permissions for now.

Record the reversal too

When a decision changes, add a new line that points back to the old one. Do not edit the first line. The history is the useful part.

Start with the next decision you make this week, and give the plan an owner while you are at it.
