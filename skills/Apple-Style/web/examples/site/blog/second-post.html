Notes that are still useful in March

Most notes stop being useful within a week, because they were written for the day they were made. Three habits change that.

Write the question, then the answer

A note that starts with the question it answers can be found by that question later. Start the title with the words a colleague would type into search.

Link the note to the card

A note in a separate document is easy to lose. Keep it on the card it belongs to, so the reason and the work stay together.

Date every line that could change

Prices, owners and deadlines change. A date beside the line tells the next reader how far to trust it.

  1. Question first, then the answer.
  2. On the card, not beside it.
  3. A date on anything that can change.

Return to the notes once a month and close the ones that no longer matter.
