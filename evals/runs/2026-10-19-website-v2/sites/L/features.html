功能介绍

少一点操作，多一点看清。

青柠记账的每个功能都围绕同一个目标：让记账花的时间更少，让你更快看懂钱去了哪里。

iPhone

随手记

语音说一句“昨天打车 32 元”即可完成记账。拍下账单或收据，金额、商户和日期会自动填入。

智能

智能分类

按商户、时间与你的修正习惯自动归类。可以添加自定义规则，例如“包含‘星巴克’归入咖啡”，规则在所有设备上生效。

Plus

周期预算

为餐饮、交通等分类设定预算，支持按周、按月或自定义周期。接近上限时提醒你，超支也只会温和地标注在报表里。

更多能力，都在身边。

月度报表

收入、支出、结余与分类占比一页呈现。与上个月对比，立刻看出变化来自哪里。

多设备同步

通过 iCloud 在 iPhone、iPad 和 Mac 之间保持一致。离线时照常记账，恢复网络后自动合并。

小组件与快捷指令

主屏幕小组件显示本周剩余预算。在“快捷指令”中添加青柠记账，就能一键记下一笔支出。

Plus

家庭共享

与伴侣或家人共享一本账，每笔记录标注付款人，月底一起核对。最多 5 位成员。

数据导出

支持 CSV、PDF 与 OFX 格式导出。你的数据随时可以带走，不需要理由。

隐私锁

使用 Face ID、Touch ID 或 Mac 触控 ID 保护应用。锁定时，小组件只显示是否超支，不显示金额。

Mac

在 Mac 上，整理更顺手。

大屏幕适合一次处理几十笔账单。拖放导入 CSV 文件，用键盘快速切换分类，也能用搜索找到任何一笔记录。

  • ⌘ N 新建一笔，⌘ Return 保存并继续
  • 拖放银行与支付账单，重复记录会被自动识别
  • 多选后批量修改分类、账户与标签
  • 与 iPhone 共用同一本账，无需手动同步
