# Northline 落地页与价格页

虚构团队协作 SaaS「Northline」的静态站点：一个落地页（`index.html`）和一个价格页（`pricing.html`）。纯 HTML / CSS / JS，无构建工具，无外部 CDN，无外部字体。内容为中文，所有公司、客户与数据均为虚构。

## 文件结构

```
Q/
├── index.html      落地页：导航、主视觉、6 个功能卖点、数字、客户评价、行动号召、页脚
├── pricing.html    价格页：方案标题与周期切换、3 张方案卡（推荐团队版）、功能对比表、FAQ、页脚
├── styles.css      共用样式：设计令牌（浅色 / 深色）、组件、响应式断点
├── script.js       主题切换（记住选择）、价格按月 / 按年切换
├── favicon.svg     站点图标
└── README.md       本说明
```

### 样式与主题

- 颜色全部定义为 `:root` 上的 CSS 变量（`--bg`、`--text`、`--accent` 等）。
- 深色主题有三处定义：跟随系统（`@media (prefers-color-scheme: dark)` 且 `:root:not([data-theme="light"])`）、手动深色（`:root[data-theme="dark"]`）。
- 导航右侧的按钮可切换浅色 / 深色，选择写入 `localStorage`（读写均包在 try/catch 中，存储不可用时页面仍正常）。
- 字体使用系统字体栈（SF / PingFang SC / Noto Sans CJK SC / 微软雅黑等），不加载任何外部资源。
- 支持 `prefers-reduced-motion`，关闭平滑滚动与过渡动画。

### 响应式

- 断点：960px（功能与方案卡改为两列或单列）、680px（导航精简，只保留「价格」与「免费开始」和主题按钮；按月 / 按年切换变为整行控件）。
- 对比表在窄屏下保持四列并压缩字号；表格外层保留横向滚动作为兜底，但页面本身无横向滚动。

## 交互

- 价格页「按月付费 / 按年付费」切换：团队版价格在 ¥68 与 ¥54 之间切换，并更新说明文字（年付合计 ¥648 / 人）。切换按钮使用 `aria-pressed` 表示状态。
- FAQ 使用原生 `<details>` / `<summary>`，无需 JS，键盘可操作。
- 所有锚点（`#features`、`#stories`、`#trial`、`#plans`、`#compare`、`#faq`）均指向页面内存在的 `id`。

## 如何预览

在本目录下启动任意静态服务器，例如：

```
python3 -m http.server 9416 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:9416/index.html` 与 `http://127.0.0.1:9416/pricing.html`。

## 检查

已在 Chromium（headless shell，Playwright 1.58.2）中完成以下检查：

1. **版式宽度**：两页在 390、768、1024、1440px 四个视口宽度下，浅色与深色各一次，`scrollWidth` 等于视口宽度（无横向页面滚动），且无元素超出视口右边界或左边界。
2. **无障碍自动扫描**：使用 axe-core 4.10.2，规则集为 WCAG 2.0 / 2.1 A 与 AA 及 best-practice。全部组合结果为 0 个违规（已修复的问题包括：标题层级跳跃、深色「待办」标签对比度不足、「按年付费」省 20% 文字对比度不足）。
3. **控制台与网络**：加载过程中无 console 错误或警告，无失败请求，无任何非本地域名的请求。
4. **交互**：主题切换（含刷新后保持）、价格周期切换与按钮状态、FAQ 鼠标与键盘（Enter）展开、导航锚点定位（固定导航不遮挡标题）、导航到价格页。
5. **链接完整性**：两页共 17 个链接（含页内锚点与跨页锚点）全部指向存在的文件与 `id`。
6. **视觉复核**：对 390px 与 1440px 的浅色、深色整页截图人工检查，修正了价格页标题在窄屏下断字的问题。

未做的事：未在真机 Safari / Android 浏览器上测试；未测量 Lighthouse 性能分数；未接入真实的注册、支付或表单。
