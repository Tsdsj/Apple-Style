Changelog

Changes to Tidepool, version by version. Dates are release dates. Versions follow semantic versioning: a major version can change the config file format or the plugin protocol.

On this page

  1. 1.4.0 · 28 September 2026
  2. 1.3.2 · 14 August 2026

1.4.0

Released 28 September 2026

Added

  • The history and restore commands.
  • An offline queue. Changes made while offline wait and sync when the connection returns.
  • The --resolve option for sync.
  • The timeout setting.

Changed

  • sync ends with a summary line that shows the bytes uploaded.

Fixed

  • status reported renamed files as one deleted and one added file.

1.3.2

Released 14 August 2026

Fixed

  • A false error E402 on some proxies, which re-sign HTTPS traffic.
  • config set removed comments from lists.
  • Plugin manifests saved with a byte order mark were rejected.

1.3.1

Released 2 July 2026

Fixed

  • --jobs values above 8 were ignored on Linux arm64.

1.3.0

Released 18 June 2026

Added

  • The after_sync hook.
  • The --exclude option for sync.
  • plugin install accepts a folder on disk.

Changed

  • In ignore patterns, ** now matches zero folders. Before, it needed at least one.

Removed

  • --no-progress. Use --quiet instead.

1.2.0

Released 9 April 2026

Added

  • The keep_history setting.
  • doctor --json.
  • Support for the NO_COLOR variable.

Changed

  • The default concurrency is 4. It was 2.

Fixed

  • Symbolic links inside root are skipped with a warning. They are no longer followed.

1.1.0

Released 20 February 2026

Added

  • plugins in the config file, with options.
  • The filter_file hook.
  • The logout command.

Changed

  • Log files moved to ~/.cache/tidepool/logs/.

1.0.0

Released 3 November 2025

The first stable release. It has the commands init, login, status, sync and pull, the config file format version 1, and plugin protocol version 1 with the filter_file and before_sync hooks.
