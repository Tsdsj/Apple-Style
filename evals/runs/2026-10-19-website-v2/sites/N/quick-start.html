Getting started

Quick start

Install Tidepool, create a project, sign in and run your first sync. The steps take about five minutes.

Last updated 28 September 2026

On this page

  2. Install

Requirements

Tidepool runs on these systems:

  • macOS 13 or later.
  • Linux on x86_64 or arm64, with glibc 2.31 or later.

Syncing needs a network connection and a token from a pool. Changes made while you are offline wait in a local queue. Windows is not supported in version 1.x.

Install

Pick one method. The installer puts the binary in ~/.local/bin/tidepool and does not need administrator rights.

Installer

curl -fsSL https://tidepool.example/install.sh | sh

Homebrew

brew install tidepool/tap/tidepool

npm

npm install --global @tidepool/cli

If tidepool is not found, open a new terminal. Then check the version:

$ tidepool version
tidepool 1.4.0 (linux/arm64, built 2026-09-28)

Set up a project

Go to the folder you want to sync and run tidepool init. Use --pool to name the pool.

$ cd ~/notes
$ tidepool init --pool notes-team
Created tidepool.yaml

The file starts with a few settings. You can change any of them later. The configuration guide lists every setting.

pool: notes-team
root: .
ignore:
  - ".git/"
  - "*.tmp"

Sign in

Create a token on the settings page of your pool, then run tidepool login. The prompt does not show the token as you type it. In a script, pipe the token in with --token-stdin instead.

$ tidepool login
Token:
Signed in to notes-team.

Note: Tidepool never writes a token to tidepool.yaml. If a token reaches a repository, revoke it on the settings page and sign in again.

Run the first sync

Check what would change before anything is sent:

$ tidepool status
Pool: notes-team (connected)
  A  inbox/2026-10-19.md
  M  plans/q4.md
2 changes, 0 conflicts

$ tidepool sync --dry-run
Would upload 2 files (3.4 KB). Nothing was sent.

$ tidepool sync
Uploaded 2 files. Revision 1 created.

Each successful sync creates a revision. List them with tidepool history, and go back to one with tidepool restore.

Next steps

  • Set ignore rules, concurrency and timeouts in the configuration guide.
  • Add behaviour with the plugins guide.
  • If something fails, start with the troubleshooting guide.
