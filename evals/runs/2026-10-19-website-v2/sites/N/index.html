Command-line tool · version 1.4.0

Sync your files to a pool, with a history you can read.

Tidepool is a small command-line tool. It sends the changes in a folder to a shared pool, keeps a numbered history of every sync, and runs plugins at the points you choose. The configuration is one YAML file in your project.

Quick start API reference

Install

Use the installer on macOS or Linux, or a package manager. All three methods install the same binary.

macOS and Linux

curl -fsSL https://tidepool.example/install.sh | sh

Homebrew

brew install tidepool/tap/tidepool

npm

npm install --global @tidepool/cli

Check the install. The command prints the version and the platform the binary was built for.

tidepool version

What it does

Three parts, each of them useful on its own.

  • A history for every sync

    Each sync creates a numbered revision. You can list them, look at the changes and restore an earlier one.

  • One file to configure

    Settings live in tidepool.yaml, next to your files. Commit it with the project and review changes like any other.

  • Plugins at fixed points

    A plugin is an executable that reads JSON lines. It can skip files, check a sync before it starts or report after it ends.

Latest release

Version 1.4.0 was released on 28 September 2026. It adds offline queueing, the history and restore commands and a --resolve option for conflicts.
