Reference

API reference

Every command, flag and environment variable of the tidepool command. Commands are grouped by task. Flags with a default value can be left out.

Synopsis

tidepool [global flags] <command> [arguments] [command flags]

Commands print human-readable output by default. Commands that accept --json print one JSON document instead, which is suitable for scripts.

Global flags

Global flags go before the command name.

Global flags
FlagTypeDefaultDescription
--config PATHpathsearch orderUse this config file. Same as TIDEPOOL_CONFIG.
-v, --verboseflagoffPrint info messages to standard error. Repeat it for debug messages.
-q, --quietflagoffPrint only errors.
--no-colorflagoffTurn colour output off.
-h, --helpflagShow help for the command and exit.
--versionflagPrint the version and exit. Same as tidepool version.

Setup

init

tidepool init [DIR] [flags]
Flags and arguments for init
Flag or argumentTypeDefaultDescription
DIRpath.Folder to set up. It is created when it does not exist.
--pool NAMEstringpromptPool name to write into tidepool.yaml.
--forceflagoffOverwrite an existing tidepool.yaml.

login

tidepool login [flags]
Flags and arguments for login
Flag or argumentTypeDefaultDescription
--token-stdinflagoffRead the token from standard input instead of prompting for it.
--endpoint URLURLconfig valueSign in to another API host.

logout

Removes the stored token. Takes no arguments and no flags.

tidepool logout

Sync and history

status

tidepool status [flags]
Flags and arguments for status
Flag or argumentTypeDefaultDescription
--jsonflagoffPrint the status as JSON.
--pool NAMEstringconfig valuePool to compare the folder with.

sync

tidepool sync [flags]
Flags and arguments for sync
Flag or argumentTypeDefaultDescription
--dry-runflagoffShow what would change. Nothing is sent.
--jobs Ninteger, 1 to 16config valueNumber of files uploaded at the same time.
--resolve MODElocal, remote or askaskHow to handle conflicts. ask prompts in a terminal. Without a terminal it stops with exit code 6.
--exclude GLOBglobnoneSkip matching paths for this run only. Repeat the flag for more patterns.
--yesflagoffDo not ask for confirmation.
--pool NAMEstringconfig valuePool to sync with.

pull

tidepool pull [flags]
Flags and arguments for pull
Flag or argumentTypeDefaultDescription
--forceflagoffReplace local changes with the pool copy.
--dry-runflagoffShow what would change. Nothing is written.
--pool NAMEstringconfig valuePool to pull from.

history

tidepool history [flags]
Flags and arguments for history
Flag or argumentTypeDefaultDescription
--limit Ninteger20Number of revisions to show, newest first.
--jsonflagoffPrint the revisions as JSON.

restore

tidepool restore REVISION [flags]
Flags and arguments for restore
Flag or argumentTypeDefaultDescription
REVISIONintegerrequiredRevision number from tidepool history.
--dry-runflagoffList the files that would change. Nothing is written.

Configuration

config get

tidepool config get KEY
Flags and arguments for config get
Flag or argumentTypeDefaultDescription
KEYstringrequiredA setting name from the configuration guide. Prints its value.

config set

tidepool config set KEY VALUE
Flags and arguments for config set
Flag or argumentTypeDefaultDescription
KEYstringrequiredA setting name from the configuration guide.
VALUEstringrequiredNew value. It is checked against the setting type before it is written.

config validate

tidepool config validate [--file PATH]
Flags and arguments for config validate
Flag or argumentTypeDefaultDescription
--file PATHpathconfig in useCheck another file instead.

Plugins

plugin list

tidepool plugin list [--json]
Flags and arguments for plugin list
Flag or argumentTypeDefaultDescription
--jsonflagoffPrint the plugins as JSON.

plugin install

tidepool plugin install SOURCE [--version V]
Flags and arguments for plugin install
Flag or argumentTypeDefaultDescription
SOURCEname or pathrequiredA plugin name from the registry, or a folder that holds a manifest.
--version VstringlatestVersion to install. Only for registry plugins.

plugin remove

tidepool plugin remove NAME
Flags and arguments for plugin remove
Flag or argumentTypeDefaultDescription
NAMEstringrequiredInstalled plugin to remove.

Diagnostics

doctor

tidepool doctor [flags]
Flags and arguments for doctor
Flag or argumentTypeDefaultDescription
--jsonflagoffPrint the checks as JSON. Tokens are hidden.
--verboseflagoffShow the details behind each check.

version

tidepool version [--json]
Flags and arguments for version
Flag or argumentTypeDefaultDescription
--jsonflagoffPrint the version, commit and build date as JSON.

Exit codes

Exit codes
CodeMeaning
0Success.
1General failure, or doctor found a failing check.
2Usage error: unknown command or flag.
3Configuration error.
4Authentication error.
5Network error.
6Sync conflict left unresolved.
7Plugin error.

Environment variables

Environment variables
VariableMeaning
TIDEPOOL_CONFIGPath to the config file.
TIDEPOOL_POOLPool name. Overrides pool.
TIDEPOOL_TOKENToken for this run. Overrides the stored token.
TIDEPOOL_LOGLog level: error, warn, info or debug.
TIDEPOOL_CA_BUNDLEExtra certificates for TLS, in PEM format.
NO_COLORTurns colour output off when set.
