Changelog

Notable changes in each release. Tidepool follows semantic versioning. Before 1.0, a minor release may contain breaking changes, and those are marked Breaking.

0.5.0 (2026-09-30)

  • Added depends_on for tasks. Cycles are reported when the file is validated.
  • Added tidepool doctor --json.
  • Added tidepool sync --locked for CI.
  • Breaking: the task key cmd is renamed to run. The old key still loads, with a warning, until 0.6.
  • Fixed: the lock file was written with CRLF line endings on Windows.

0.4.2 (2026-08-14)

  • Fixed: cache prune --older-than ignored its argument.
  • Fixed: fish completion did not offer plugin names.

0.4.0 (2026-07-02)

  • Added plugin hooks, starting with after_sync.
  • Added tidepool plugin update.
  • Breaking: lock file format v2. Run tidepool sync once after upgrading to regenerate tidepool.lock.

0.3.0 (2026-05-20)

  • Added local overrides in tidepool.local.toml.
  • Added tidepool run --dry-run.
  • Added tidepool cache prune.

0.2.0 (2026-03-11)

  • Added plugins, with SHA-256 checksum verification.
  • Added tidepool plugin add, remove and list.

0.1.0 (2026-01-15)

  • First public release: init, run, config and --version.
