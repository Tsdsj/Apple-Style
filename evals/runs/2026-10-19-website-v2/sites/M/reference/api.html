Reference

API reference

Tidepool's public interface is its command line and the tidepool.toml schema. This page lists every command, flag and environment variable. Exit codes are listed in Troubleshooting.

Synopsis

tidepool [GLOBAL FLAGS] COMMAND [COMMAND FLAGS] [ARGUMENTS]

Uppercase words are placeholders. Square brackets mark optional parts.

Global flags

FlagDefaultDescription
--config PATHsearched upwardUse this config file. Overrides TIDEPOOL_CONFIG.
-v, --verboseoffPrint more output. Repeat for more detail.
-q, --quietoffPrint errors only.
--no-coloroffDisable colors. NO_COLOR has the same effect.
-h, --helpShow help for the command and exit.
--versionPrint the version and exit.

Commands

init

tidepool init [DIR] [--force] [--template NAME]

Creates tidepool.toml in DIR, or in the current directory. Refuses to overwrite an existing file unless --force is given.

Flag or argumentDefaultDescription
DIR.Directory to initialize.
--forceoffOverwrite an existing tidepool.toml.
--template NAMEminimalStarter template. One of minimal, node, python or c.

sync

tidepool sync [--locked] [--offline] [--jobs N]

Resolves, downloads and installs plugins, then writes tidepool.lock.

FlagDefaultDescription
--lockedoffFail with exit code 3 if the lock file would change. Use in CI.
--offlineoffUse only artifacts already in the cache.
--jobs N4Number of parallel downloads. TIDEPOOL_JOBS sets the same default.

run

tidepool run TASK [--timeout DURATION] [--no-deps] [--force] [--dry-run] [-- ARGS...]

Runs a task and its depends_on tasks. Arguments after -- are appended to the task's command.

Flag or argumentDefaultDescription
TASKrequiredName of a task in [tasks].
--timeout DURATIONtask settingOverrides the task's timeout.
--no-depsoffSkip depends_on tasks.
--forceoffIgnore cached results and run the task anyway.
--dry-runoffPrint the resolved command and exit without running it.

plugin

tidepool plugin add NAME [--version CONSTRAINT]
tidepool plugin remove NAME
tidepool plugin list [--json]
tidepool plugin update [NAME]
SubcommandDescription
add NAMEAdds [plugins.NAME] to the configuration. --version CONSTRAINT sets the version range. Without it, Tidepool uses a caret range around the newest release.
remove NAMERemoves the plugin from the configuration and the lock file.
listShows the plugins in the project. --json prints JSON.
update [NAME]Moves plugins to the newest release their constraint allows. Without NAME, updates every plugin.

config

tidepool config get KEY
tidepool config set KEY VALUE
tidepool config validate [--strict]
SubcommandDescription
get KEYPrints the value at a dotted key, for example tasks.build.timeout.
set KEY VALUEWrites a value into tidepool.toml, leaving comments in place where possible.
validateChecks the file. --strict treats warnings as errors. Exits with code 3 on errors.

doctor

tidepool doctor [--json]

Runs health checks on the config, the binary, the cache and each plugin. Exits with code 1 if any check fails. See Troubleshooting.

cache

tidepool cache prune [--older-than DURATION]

Deletes cached downloads and task results that have not been used recently. --older-than defaults to 30d.

completion

tidepool completion SHELL

Prints a completion script for SHELL, which is bash, zsh or fish. For example, tidepool completion bash > ~/.local/share/bash-completion/completions/tidepool installs it for bash.

Environment variables

VariableDefaultDescription
TIDEPOOL_CONFIGsearched upwardPath to the configuration file.
TIDEPOOL_HOME~/.tidepoolDirectory for the cache and installed plugins.
TIDEPOOL_LOGinfoOne of error, warn, info, debug or trace.
TIDEPOOL_JOBS4Default for sync --jobs.
NO_COLORunsetDisables colored output when set to any non-empty value.
