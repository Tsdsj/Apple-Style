Before you begin

You need Tidepool 0.5.0 or later, a POSIX shell (bash, zsh or fish) and, optionally, git. If Tidepool is not installed yet, follow the steps in the introduction.

1. Create a project

Make a directory and let Tidepool write a starter configuration into it:

$ mkdir hello-pool && cd hello-pool
$ tidepool init
created tidepool.toml

The starter file is short. Its name comes from the directory name:

name = "hello-pool"
version = 1

[tasks.hello]
run = "echo Hello from Tidepool"

2. Run a task

Tasks are named commands. Run the hello task:

$ tidepool run hello
[hello] running: echo Hello from Tidepool
Hello from Tidepool
[hello] done in 0.02s

3. Add a plugin

Plugins bring in tools and tasks maintained by someone else. Add the node plugin, then install it:

$ tidepool plugin add node
added node 2.1.4 (source tidepool/node); run `tidepool sync` to install
$ tidepool sync
resolving 1 plugin
  node 2.1.4 ... ok
wrote tidepool.lock

The first command also adds a [plugins.node] table to tidepool.toml. Commit the configuration and the lock file together:

$ git add tidepool.toml tidepool.lock
$ git commit -m "Add Tidepool configuration"

4. Check the setup

$ tidepool doctor
[ok]   config    tidepool.toml parsed (schema v1)
[ok]   plugins   1 plugin installed, lock file current
Summary: 2 ok, 0 warnings, 0 failures
