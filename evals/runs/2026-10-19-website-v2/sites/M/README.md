# Tidepool 文档站

这是虚构命令行工具 Tidepool 的文档站，纯静态 HTML/CSS/JS：没有构建步骤，没有外部 CDN、字体或脚本。站点内容为英文，Tidepool 及其命令、配置、版本号均为虚构示例。

## 结构

```
sites/M/
├── index.html                 首页：简介、安装命令、导航卡片
├── quick-start.html           快速开始
├── guides/
│   ├── configuration.html     指南：配置（tidepool.toml、任务、环境变量、本地覆盖）
│   ├── plugins.html           指南：插件（安装、版本约束、锁文件、编写插件）
│   └── troubleshooting.html   指南：故障排查（doctor 输出、常见错误、退出码）
├── reference/
│   └── api.html               API 参考：全局参数、命令与参数表格、环境变量
├── changelog.html             更新日志
├── 404.html                   404 页面
├── assets/
│   ├── style.css              样式：颜色变量、浅色/深色、三档响应式布局
│   └── app.js                 主题切换、移动端菜单、复制按钮、页内目录高亮
└── README.md
```

每个页面都是独立的完整 HTML 文件，页面之间用相对路径链接，因此站点可以直接用任何静态服务器托管在域名根目录下。

## 页面与交互

- **顶部栏**：站点名与版本号、顶部链接（不足 640px 时隐藏）、深色/浅色切换按钮。
- **文档导航**：宽度 900px 及以上时左侧常驻侧边栏，当前页用 `aria-current="page"` 标出。更窄时侧边栏收进 "Menu" 按钮打开的抽屉，按 Esc 或点击链接即关闭。
- **页内目录**：1200px 及以上时在右侧固定显示，并随滚动高亮当前章节。更窄时在正文开头显示为可折叠的 "On this page"。
- **代码块**：`pre` 元素横向滚动、不换行，可用键盘聚焦；右上角有复制按钮（需要 HTTPS 或 localhost 才能使用剪贴板）。
- **表格**：外层容器横向滚动，窄屏下页面本身不会出现横向滚动条。
- **上一页/下一页**：每个文档页底部，按导航顺序排列。
- **主题**：默认跟随系统的 `prefers-color-scheme`。按钮可以强制切换，选择保存在 `localStorage` 中；读写都包在 try/catch 里，存储不可用时只在当前页生效。颜色全部定义为 `:root` 上的变量，深色值在 `@media (prefers-color-scheme: dark)` 中（受 `:root:not([data-theme="light"])` 守卫）以及 `:root[data-theme="dark"]` 中各定义一份。
- **404**：`404.html` 使用根路径链接（`/index.html`、`/assets/style.css`）。托管时需要把未知路径映射到 `404.html`，并返回 404 状态码。

## 本地预览

预览端口为 9414。在站点目录外执行：

```
python3 -m http.server 9414 --bind 127.0.0.1 --directory /home/user/Apple-Style/evals/runs/2026-10-19-website-v2/sites/M
```

注意：`http.server` 对未知路径返回它自己的 404 页面，不是 `404.html`。若要预览真正的 404 页面，直接访问 `/404.html`。

### 维护者可以手动复查的项目

- 修改任何页面后，用上面的预览命令打开，分别在 375px（手机）和 1280px（桌面）宽度下看一遍，并切换深色模式。
- 确认表格和代码块在窄屏下只在自身内部滚动，页面没有横向滚动条。
- 用键盘（Tab、Enter、Esc）走一遍菜单和复制按钮。
- 新增页面时，需要同时更新**所有页面**的侧边栏导航、顶部链接（如有需要）以及上一页/下一页顺序。

## 维护说明与限制

- 当前页面的 HTML 由一次性 Python 脚本生成，生成脚本不在站点目录中。之后直接编辑 HTML 即可，不需要再运行生成脚本。导航、页头、页脚与页内目录在每个页面中各有一份，修改时要逐页同步。
- 页面内部链接是相对路径，适合放在域名根目录下。如果部署在子路径（例如 `example.com/docs/`），需要确认 `404.html` 中的根路径链接（`/index.html` 等）是否仍然正确，并相应调整。
- 站点没有全文搜索，代码块也没有语法高亮。
- 安装地址 `https://tidepool.example/install.sh` 与 `tidepool/tap/tidepool` 均为虚构示例，`.example` 是保留域名，不会解析到真实站点。
