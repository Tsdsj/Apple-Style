Plugins

Plugins add tools, tasks and checks to Tidepool. A plugin is a versioned package that tidepool sync downloads, verifies and installs.

Adding a plugin

Add a plugin with the CLI, or write the table yourself:

$ tidepool plugin add node --version "^2.1"
added node 2.1.4 (source tidepool/node); run `tidepool sync` to install

This writes a table into tidepool.toml:

[plugins.node]
source = "tidepool/node"
version = "^2.1"

Then run tidepool sync to download and install the plugin. Without --version, Tidepool pins the newest release and writes a caret range around it, such as ^2.1.4.

Managing plugins

$ tidepool plugin list
NAME  VERSION  CONSTRAINT  STATUS
node  2.1.4    ^2.1        installed

$ tidepool plugin update node    # newest release allowed by the constraint
$ tidepool plugin remove node

Version constraints

ConstraintAcceptsNotes
2.1.4exactly 2.1.4Pins one release.
~2.12.1.0 up to, but not including, 2.2.0Patch updates only.
^2.12.1.0 up to, but not including, 3.0.0Minor and patch updates. The default style.
*any releaseNot recommended for shared projects.

The lock file

tidepool sync writes tidepool.lock with the exact version and checksum of every plugin it installed. Commit the lock file. In CI, run tidepool sync --locked, which fails instead of changing the lock file:

[[plugin]]
name = "node"
source = "tidepool/node"
version = "2.1.4"
sha256 = "9f2c4e7a0d18b6c3e5a2f94d71c0b8e6a3d5f2c19e7b4a80d6c3f1e2b9a7d540"

Writing a plugin

A plugin is a directory with a plugin.toml manifest and any executables it needs:

my-plugin/
  plugin.toml
  bin/
    after-sync

The manifest names the plugin and the hooks it provides:

name = "my-plugin"
version = "0.1.0"
description = "Format generated files after sync"

[hooks]
after_sync = "bin/after-sync"

Hooks are executables. Tidepool starts each hook with a JSON description of the project on standard input, and reads one JSON object from standard output. A non-zero exit status fails the step, and Tidepool prints whatever the hook wrote to standard error. The available hooks are before_sync, after_sync, before_run and after_run.

Trust and security

Plugins run with your user's permissions. Tidepool checks SHA-256 checksums against the lock file, but it does not sandbox plugin processes. Install only plugins you trust, and read the plugin.toml of a plugin before you add it to a shared project.
