Troubleshooting

Most problems show up in tidepool doctor. This page explains its output, the exit codes, and the errors people hit most often.

Start with doctor

tidepool doctor checks the configuration, the binary, the cache and every installed plugin. Each line is ok, warn or fail:

$ tidepool doctor
[ok]   config        tidepool.toml parsed (schema v1)
[ok]   binary        tidepool 0.5.0 (linux/x86_64)
[warn] cache         4.2 GB in ~/.tidepool/cache; run `tidepool cache prune`
[fail] plugin node   lock file is out of date; run `tidepool sync`
Summary: 2 ok, 1 warning, 1 failure

doctor exits with code 1 when any check fails. Add --json for machine-readable output, which is useful when you attach results to a bug report.

Common errors

No tidepool.toml found

error: no tidepool.toml found (searched from /home/you/app to /)

Tidepool searched the current directory and its parents. Run tidepool init in the project root, or pass --config PATH. Exit code 3.

Lock file is out of date

error: lock file is out of date; run `tidepool sync` and commit tidepool.lock

tidepool sync --locked found plugin requirements that differ from tidepool.lock. Run tidepool sync on your machine, review the change to the lock file, and commit it. Exit code 3.

Checksum mismatch

error: checksum mismatch for node 2.1.4
  expected 9f2c4e7a...a7d540
  got      1b08c3e6...0f2a1f

The downloaded archive is not the one recorded in the lock file. Causes include a corrupted download, a proxy that rewrites responses, and a plugin release that was replaced after publication. Run tidepool cache prune and try again. If the error persists, do not edit the lock file by hand. Report it instead. Exit code 5.

Permission denied on the cache

error: permission denied: /home/you/.tidepool/cache

This usually means an earlier Tidepool run used root. Fix the ownership of ~/.tidepool, or point Tidepool somewhere else with TIDEPOOL_HOME. Avoid sudo for normal commands, because it leaves root-owned files in your home directory.

Network request failed

Exit code 4. Make sure any proxy settings are present in the environment that Tidepool runs in. Run with TIDEPOOL_LOG=debug to see the URL and status code of each request. If you only need what is already cached, use tidepool sync --offline.

Task timed out

error: task "build" timed out after 5m

A task is stopped when it reaches its timeout, which defaults to 10m. If the task is legitimately slow, raise the limit in tidepool.toml or in tidepool.local.toml. Exit code 124 matches timeout(1).

Exit codes

CodeMeaning
0Success.
1Generic failure, or doctor found a failing check.
2Usage error, such as an unknown flag.
3Configuration or lock file error.
4Network error while fetching plugins.
5Checksum mismatch.
124A task timed out.

Getting more detail

  • -v prints each step. -vv also prints the commands that tasks run.
  • TIDEPOOL_LOG=trace logs everything, including HTTP headers. Remove tokens before you paste logs anywhere.
  • Include the output of tidepool doctor --json and tidepool --version in bug reports.
