Tidepool

Tidepool keeps a project's tools, plugins and tasks in sync across machines. You describe everything in one file, tidepool.toml, that lives next to your code.

On this page
  • Install
  • Why Tidepool
  • Where to next

Install

Download and run the install script:

$ curl -fsSL https://tidepool.example/install.sh | sh

Or install with Homebrew on macOS and Linux:

$ brew install tidepool/tap/tidepool

Then confirm the binary is on your path:

$ tidepool --version
tidepool 0.5.0 (linux/x86_64)

Why Tidepool

  • One file. Tools, plugins and tasks live in tidepool.toml. Review changes to your environment the same way you review code.
  • Reproducible. tidepool sync resolves plugin versions, verifies SHA-256 checksums and records the result in tidepool.lock.
  • Small. Eight commands and no background daemon. Tidepool only uses the network during sync and plugin add or plugin update.
  • Portable. Linux, macOS and Windows through WSL, on x86_64 and arm64.
