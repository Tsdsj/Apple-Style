# 文稿窗口原型：700 px 与 1440 px

macOS 文档编辑应用的窗口原型，包含文稿列表、编辑区和可选属性面板。两个宽度共用同一个页面，按视口宽度切换布局。

## 打开方式

- `index.html`：完整视口中的原型。用浏览器打开后，把窗口拖到 700 px 或 1440 px 宽即可看到对应布局。
- `preview.html`：把两种宽度并排（上下排列）显示在一个页面里。
- 本地预览：`python3 -m http.server 9431 --directory <本目录>`，然后访问 `http://127.0.0.1:9431/index.html`。

示例数据为虚构内容。界面为中文，保存只在内存中进行，刷新后恢复示例数据。

| `js/liquid-glass.js` | Apple-Style 运行时，负责列表键盘模型、分隔线、菜单快捷键和提示 |

## 页面类型

按 Apple-Style 的页面类型表，这是 **Deliberate Mac-like window**（用户要求 Mac 应用窗口）。因此没有网站页眉、页脚或底部标签栏，窗口外框由工具栏承担，三个面板都是内容层的实体背景，玻璃只用于框架内的工具栏。它是浏览器里的应用界面，不假装是原生应用。

## 两种宽度的布局

| | 700 px | 1440 px |
|---|---|---|
| 布局层 | 窗口层从 640 px 起生效（原为 1024 px） | 窗口层原样，≥1280 档 |
| 菜单栏、工具栏 | 同一套结构，工具栏标题可截断 | 同 |
| 文稿列表 | 240 px，固定宽度 | 280 px，可用分隔线拖动或 ←/→ 调整 |
| 编辑区 | 余下宽度，约 459 px；正文阅读宽不超过 672 px | 约 778 px（属性展开时）；正文居中，阅读宽 672 px |
| 属性面板 | 默认隐藏。打开后覆盖编辑区，列表仍可操作，编辑区设为 inert | 默认展开，380 px，与编辑区并排，可拖动分隔线 |
| 分隔线 | 隐藏 | 显示 |
| 搜索 | 列表顶部 | 同 |
| 横向滚动 | 无 | 无 |

窗口宽度跨过 1024 px 时，属性面板在“并排”和“覆盖”两种方式之间切换，状态保持不变，不会自动隐藏。

**为什么搜索放在列表顶部，而不在工具栏。** 700 px 下工具栏要放下列表切换、标题、新建、属性切换和分享，再加一个 200 px 搜索框，标题会被截断。两种宽度统一把搜索放在列表顶部，搜索的对象就是列表。这与 HIG 工具栏的分组建议不同，是本项目的取舍。

## 键盘焦点

Tab 顺序（1440 px，实测）：

菜单栏（整个菜单栏只有一个停靠点，←/→ 切换标题） → 工具栏：文稿列表、新建、属性、分享 → 搜索框 → 文稿列表（一个停靠点，↑/↓、Home/End 选择，选中项即加载到编辑区） → 列表分隔线 → 标题 → 正文 → 属性分隔线 → 属性控件（状态、标签、允许评论、复制链接、导出 PDF）

700 px 下列表分隔线和属性分隔线不存在。属性面板隐藏时，它的控件不在 Tab 顺序中。覆盖式属性打开时，Tab 不会进入被覆盖的编辑区。

在列表中按 Enter，焦点进入标题；在搜索框中按 ↓ 或 Enter，焦点进入结果列表。

### 快捷键

| 操作 | Mac | 其他系统（原型中 ⌘ 对应 Ctrl） |
|---|---|---|
| 显示或隐藏文稿列表 | ⌥⌘S | Alt+Ctrl+S |
| 显示或隐藏属性 | ⌥⌘I | Alt+Ctrl+I |
| 导出为 PDF | ⇧⌘E | Shift+Ctrl+E |
| 关闭覆盖式属性 | Esc | Esc |

没有给“新建文稿”设快捷键。⌘N 是浏览器保留的组合键。

### 面板隐藏和显示时的焦点

| 情况 | 焦点去向 |
|---|---|
| 焦点在将被隐藏的面板内，用快捷键或菜单隐藏 | 编辑区标题（列表隐藏时）；属性切换按钮（属性隐藏时） |
| 焦点在工具栏按钮上，点击它隐藏面板 | 焦点留在按钮上（按钮仍可见） |
| 通过菜单隐藏或显示 | 菜单关闭后，焦点回到菜单栏的“显示”，前提是焦点仍在菜单内 |
| 内联面板显示（快捷键或按钮） | 焦点不动，输入可以继续 |
| 覆盖式属性显示 | 焦点移到属性标题（覆盖内容时需要明确的焦点落点） |
| Esc 关闭覆盖式属性 | 焦点回到属性切换按钮 |
| 窗口由宽变窄，焦点在编辑区，属性面板已打开 | 焦点移到覆盖式属性标题，编辑区设为 inert |
| 关闭覆盖式属性的“关闭”按钮 | 焦点回到属性切换按钮 |

## 隐藏面板的恢复方式

面板被隐藏后，有四种途径恢复，互不依赖：

1. **工具栏切换按钮。** “文稿列表”在工具栏最左，“属性”在工具栏右侧。两者始终可见，用 `aria-pressed` 表示是否显示，名称保持不变。
2. **快捷键。** ⌥⌘S 和 ⌥⌘I 在页面任何位置都有效（正文中已测试）。
3. **显示菜单。** 菜单项文字随状态切换（“隐藏文稿列表”/“显示文稿列表”，“显示属性”/“隐藏属性”），与快捷键、工具栏按钮调用同一个处理函数。
4. **覆盖式属性的关闭按钮和 Esc。** 只在 700 px 下出现。

面板不会从 DOM 中移除，只是设置 `hidden`。窗口宽度变化不会改变用户已经选择的显示状态。原型不记住上次的显示状态，每次加载都从默认状态开始。

## 设计依据

依据标注沿用 Apple-Style 的规则强度分类。以下引用来自技能的 cheatsheet（`layout-and-shapes.md`、`web-app.md`），我没有逐条回到 `Apple-Style-HIG/reference/` 核对原文。

- **官方推荐（HIG 文字，经技能引用）**：窗口底部不放关键操作；工具栏位于窗口框架内，工具栏项不带边框；侧栏不超过两级，更深的层级用内容列；属性检查器位于尾部，是可选的；分隔线使用细线，拖动区域加宽。
- **项目默认**：240 / 280 / 380 px 的面板宽度，672 px 阅读宽，640 px 的窗口层下限。这些数字是起点，不是 Apple 的规定。
- **项目决定**：窄窗口中属性以覆盖方式出现，而不是挤压编辑区。规则文件允许“折叠或披露面板而不改变平台身份”。
- **视觉启发式**：面板使用实体背景，玻璃只在工具栏框架内使用。

## 已知偏差

1. **窗口层下限从 1024 降到 640。** `css/window.css` 中 `@media (min-width: 1024px)` 改为 `@media (min-width: 640px)`，并加了注释。原因是 700 px 需要同一套窗口框架。技能原本只为 ≥1024 px 设计了窗口层，640 px 以下未验证。
2. **属性覆盖层、分隔线隐藏、CJK 字体回退**都在 `css/doc-app.css` 中，不是 Apple-Style 原有的规则。

## 发现的上游问题

这些问题在技能的源文件中，本次未修改 `skills/` 目录。

1. **`window.css`：隐藏的属性面板仍然显示。** 规则 `.as-split > .as-inspector { display: block }` 排在 `.as-split > [hidden] { display: none }` 之后，两者特异性相同，前者胜出。在技能自带的 `web/demo-desktop.html` 中验证：点击 `#tInspector` 后，`hidden` 为 `true`，但 `display` 仍是 `block`，面板宽 380 px，依然可见。修正办法：把 `[hidden]` 规则放在后面，或加 `!important`。本原型用的是后者。
2. **`liquid-glass.js`：⌥⌘I 在正文中被忽略。** `fieldOwns()` 把 ⌘I（斜体）视为富文本编辑键，但没有检查是否同时按下了 Option，所以焦点在 `contenteditable` 中时，⌥⌘I 直接失效。本原型在应用层处理 ⌥⌘I 和 ⌥⌘S，并调用 `preventDefault()`，运行时因此跳过。建议上游：编辑键保留只在没有 Alt 时生效。
3. **`window.css`：分隔线在 640–1023 px 重新出现。** 窗口层下限降低后，`.as-split > .as-split-divider { display: block }` 覆盖了原本的隐藏规则。本原型在 `doc-app.css` 中补回隐藏。
4. **`tokens.css`：`--as-font-text` 没有 CJK 回退。** 中文文字会落到系统默认字体。本原型在 `doc-app.css` 中加入了 PingFang SC 等字体。

## 验证记录

环境：Chromium headless shell（`/opt/pw-browsers/chromium_headless_shell-1194`，Playwright 1.58.2），本地服务 `127.0.0.1:9431`，axe-core 4.10.2。脚本和截图保存在 scratchpad，不在本目录中。

**已检查（67 项断言全部通过）**

- **布局**：700、1024（分界）、1440 px 下无横向滚动；1440 px 下列表 280、属性 380，三栏和分隔线正好填满窗口；窗口高度等于视口高度（100dvh）。
- **焦点与快捷键**：⌥⌘S、⌥⌘I、⇧⌘E 各只触发一次；焦点按上表移动；覆盖式属性打开时编辑区 inert，Tab 不进入编辑区；Esc 关闭并回到切换按钮；隐藏面板时焦点不会留在不可见元素上。
- **列表**：↑/↓/Home/End 选择并加载文稿；Enter 进入标题；搜索过滤；空结果提示。
- **分隔线**：方向键调整宽度，`aria-valuenow` 与实际绘制宽度一致。
- **菜单**：打开、←/→ 切换、Esc 关闭并恢复焦点、Enter 执行命令。
- **窗口缩放**：1440 → 700 → 1440，属性面板打开时，焦点、覆盖和 inert 状态正确切换。
- **axe-core 4.10.2**：700 与 1440 px，浅色与深色，以及 700 px 下覆盖式属性打开时，均无 serious 或 critical 违规。
- **对比度（计算值，按背景合成）**：浅色和深色各 13 个探针，全部 ≥ 4.5:1。浅色最低 4.72:1（属性字段标签），深色最低 5.15:1（选中行上的分享按钮）。
- **偏好设置**：减少动态效果与强制颜色同时开启时，覆盖式属性仍能打开，焦点正确移动（仅冒烟检查）。
- **控制台**：所有运行中无页面错误、控制台错误或警告。
- **视觉**：人工查看了 700 px 覆盖式属性，以及 1440 px 默认和属性隐藏的截图。700 px 默认和列表隐藏的截图只在测试中生成，未逐张查看。

- VoiceOver、NVDA 等辅助技术的实际朗读。axe 只检查了静态结构。
- macOS 上的 ⌥/⌘ 键行为。测试只在 Linux 上进行，按 Ctrl/Alt 映射。
- 触摸设备（`any-pointer: coarse`）下的行高和命中区域。
- **中文输入法（IME）在正文和标题中的组合输入**。这是中文编辑器的关键路径，本次未测。
- 减少透明度、增强对比度的实际效果（只做了强制颜色的冒烟检查）。
- 640 px 以下的宽度、2000 px 以上的宽度、性能和渲染开销。
- 保存、撤销、重做和真实文档持久化。原型只在内存中保存。
