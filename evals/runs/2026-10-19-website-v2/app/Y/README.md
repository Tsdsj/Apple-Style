# macOS 文档编辑器窗口：700 与 1440

为 macOS 风格的文档编辑应用设计两种窗口宽度：700px（紧凑）和 1440px（完整）。窗口包含文档列表、编辑区和可选的属性面板，并给出键盘焦点模型与隐藏面板的恢复方式。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 原型。同一窗口结构渲染两次：700 × 620 与 1440 × 900。 |
| `apple-style.css` | 来自 Apple-Style skills 的 `web/`，原样复制，未修改。 |
| `liquid-glass.js` | 同上。提供分隔线、列表、开关的键盘与 ARIA 行为。 |
| `README.md` | 本文件。 |

预览：在本目录运行 `python3 -m http.server 9432`，然后打开 `http://127.0.0.1:9432/index.html`。容器内的 9432 端口已在运行。

## 窗口规格

| | 700 宽（紧凑） | 1440 宽（完整） |
|---|---|---|
| 工具栏 | 框内工具栏：列表开关、标题、新建、属性开关、搜索（150px）、共享 | 同上，搜索 200px |
| 文档列表 | 200px，常显，可隐藏 | 264px，可拖动（180–360），可隐藏 |
| 编辑区 | 填满剩余宽度（实测 500px） | 实测 794px |
| 属性 | 默认关闭。打开后是 280px 浮层，贴右缘，覆盖编辑区 | 380px，常显，可拖动（240–520），可隐藏 |
| 分隔线 | 隐藏（没有空间） | 显示 |
| 正文列 | 不超过 672px，左右留白 24px | 同左 |

布局由窗口自身宽度决定（容器查询），不由浏览器视口决定。`apple-style.css` 的分栏规则以视口为条件，这里不直接依赖它。

中间宽度也已测量（只改窗口宽度，不在页面中单独展示）：

- 1100 宽：列表 220 / 编辑区 578 / 属性 300，与 `apple-style.css` 的 1024–1279 档位一致。
- 900 宽：属性变为浮层，编辑区 700。

### 为什么 700 不直接堆叠

`apple-style.css` 在 1024px 以下把分栏堆叠为上下排列。对文档编辑器来说，这会把编辑区压到列表下面，实际无法使用。因此 700 宽采用单独的紧凑方案：列表与编辑区并排常显，属性改为可关闭的浮层。

### 为什么属性浮层是实色

浮层覆盖正文，实色面板可以保证正文不受干扰。HIG 把玻璃材质限定在导航和控制层，浮层是否采用玻璃属于设计选择，这里没有测试玻璃版本。

## 键盘焦点

**Tab 顺序**（窗口内，按 DOM 顺序）：

1. 工具栏：列表开关 → 新建 → 属性开关 → 搜索 → 共享
2. 文档列表：单一 Tab 停靠点。↑ ↓ 切换并打开文档，Home / End 跳到首尾。
3. 列表分隔线（仅 1440）
4. 编辑区：标题 → 正文
5. 属性分隔线（仅 1440）
6. 属性：状态、标签、允许评论开关

**F6 / ⇧F6** 在区域之间循环：工具栏 → 列表 → 编辑区（标题）→ 属性。隐藏的区域会被跳过。在 700 宽下，属性区域的焦点落在标题上。

**快捷键**（网页近似）：

| 操作 | 按键 |
|---|---|
| 显示或隐藏文档列表 | ⌥⌘S |
| 显示或隐藏属性 | ⌥⌘I |
| 在区域间前后循环 | F6 / ⇧F6 |
| 关闭 700 宽的属性浮层 | Esc |

网页只绑定了这些组合。`⌘N`、`⌘F` 是浏览器保留的快捷键，原型没有绑定。原生应用应使用系统标准快捷键，并把这些命令放在菜单栏中。

**焦点规则**：

- 焦点所在的面板被隐藏时，焦点移到该面板的开关，不会落到页面主体上。
- 用键盘显示面板时，焦点进入面板：列表进入当前选中行，属性进入第一个字段。
- 用鼠标显示面板时，焦点留在开关上。例外：700 宽的属性浮层总是把焦点移到其标题，因为它的行为类似弹出层。
- 浮层的关闭方式：Esc（焦点回到属性开关）、再次点击开关、在浮层外按下指针。键盘焦点移入编辑区不会关闭浮层。
- 焦点环使用 `:focus-visible` 的 2px 强调色外框，不依赖阴影。

## 隐藏面板的恢复

1. **开关始终可见。** 工具栏里的两个开关不随面板隐藏。它们的 `aria-pressed` 和名称随状态切换（"隐藏文档列表" / "显示文档列表"）。
2. **快捷键。** ⌥⌘S 与 ⌥⌘I 可在任何焦点位置使用，包括在列表或编辑区内。
3. **播报。** 每次显示或隐藏都通过一个隐藏的 `role="status"` 区域播报。
4. **空间回收。** 列表隐藏后，编辑区（1440 宽下）从 794px 扩展到 1059px，没有空白留白。恢复后列表回到之前的宽度。
5. **分隔线随面板隐藏**，恢复后可用。

## 文档列表的状态

列表有四种状态，并以 `data-list-state` 标示：

- **加载**：骨架屏，列表容器 `aria-busy="true"`。
- **已填充**：文档行，单选，见上文键盘规则。
- **空**：无匹配结果，或无文档（带"新建文档"按钮）。无匹配的情况已测试；无文档的情况只有代码路径，原型没有删除功能，因此没有测试。
- **错误**：说明错误并提供"重试"按钮。原型中通过派发 `dw:error` 事件进入此状态，正式使用时应由数据层触发。

## 视觉与无障碍取值

- 颜色全部来自 `apple-style.css` 的语义令牌。深色模式跟随系统。
- Mac 密度：界面文字 13px / 16px，控件按 `data-platform="macos"` 缩小。
- 正文编辑区 15px / 24px。这是文档内容的项目取值，不是 HIG 规定。
- 文档列表行高 44px，因为每行包含标题和元信息两行。这高于 macOS 单行侧栏行的 28px。
- 中文字体栈加入了 PingFang SC、Noto Sans CJK SC、Microsoft YaHei 等。在 macOS 上应显示 PingFang SC。
- 工具栏按钮不加描边，符合 macOS 窗口工具栏的写法。
- 窗口外框圆角 12px 是原型取值。原生窗口的圆角和红黄绿按钮由系统绘制，原型没有绘制。

## 已知限制

- **浏览器可能截获部分按键（未在真实浏览器中验证）。** 例如 F6 在某些浏览器中可能聚焦地址栏，⌥⌘I 可能与 DevTools 快捷键冲突。工具栏按钮始终可用，不依赖快捷键。
- **工具栏样式依赖视口宽度。** `apple-style.css` 的 `.as-toolbar-window` 规则只在视口 ≥1024px 时生效。如果在更窄的浏览器窗口中打开原型，工具栏会退回基础样式（未测试）。
- **数据是静态的。** 文档、列表、保存状态都只存在于页面内存中，没有持久化。"已自动保存" 只是界面文字。
- **浮层遮挡编辑区。** 700 宽下浮层打开时覆盖约 56% 的编辑区。如果编辑时需要同时看到属性，可以考虑在 700 宽下隐藏列表，或把浮层做得更窄。原型未测试这种取舍。
- **分栏宽度是起点，不是 Apple 的数值。** 264 / 380 与 220 / 300 来自 `apple-style.css`，应以你的内容实测后调整。
