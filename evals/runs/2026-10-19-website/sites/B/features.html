记账

3 秒，记一笔。

金额、分类、完成。没有多余的步骤，也不会追问你“这笔钱花得值不值”。

    在同一家店消费过一次，下次分类和账户就替你选好了。

  • 快捷指令与 Siri

    对 Siri 说“用青柠记一笔 32 元午餐”，或者把记账加入你的自动化流程。

  • 小组件与控制中心

    主屏幕、锁定屏幕和控制中心都能一键记账，不必打开 App。

  • 周期账单

    房租、会员、话费按周期自动入账，到期前提醒你确认。

  • 扫描小票 Pro

    拍下小票，在设备上识别金额、商家和日期，图片不会上传。

预算

还能花多少，一眼就知道。

预算不是为了约束你，而是让你花钱时心里有数。

  • 总预算与分类预算

    先设一个月度总预算就够了；想更细，再给餐饮、购物单独设上限。分类预算为 Pro 功能。

  • 滚动结余 Pro

    这个月没花完的预算自动滚入下个月；超支的部分也会温和地从下个月扣除。

  • 温和的提醒

    用到 80% 时轻轻提醒一次，不会每花一笔就弹出红色警告。

  • 储蓄目标

    为旅行、换新电脑设一个目标，看着进度条一点点变满。

账户

所有账户，放在一处。

现金、储蓄卡、信用卡、电子钱包，余额一屏看完，再也不用逐个打开查。

  • 多账户

    免费版支持 3 个账户，Pro 不限数量。转账、还款会自动在两个账户间对冲，不会重复计入支出。

  • 信用卡还款提醒

    设置账单日和还款日，到期前三天提醒，不再错过还款。

  • 多币种与自动汇率 Pro

    出国旅行用当地货币记账，按当日汇率自动换算成人民币。

同步与隐私

处处同步，只属于你。

青柠没有自己的账号系统，也没有自己的云。你的账本通过你自己的 iCloud 在设备间同步。

  • iCloud 同步，免费

    在 iPhone 上记的账，几秒后出现在 Mac 上。同步不该是付费功能。

  • 家人共享 Pro

    邀请家人加入同一个账本，最多 6 人，各记各的，统一查看。

  • 面容 ID 与触控 ID

    打开 App 需要验证；切到后台时自动模糊界面，不怕旁人瞥见。

  • 没有广告与追踪

    不接入任何广告或第三方统计 SDK。详见隐私政策。

菜单栏快速记账

默认快捷键 Control + Option + 空格，在任何 App 里弹出记账面板。

键盘优先

Command + N 记一笔，Command + F 搜索，几乎每个操作都有快捷键。

导入银行账单

拖入银行或支付平台导出的 CSV 账单，自动匹配分类、识别重复记录。

批量编辑

多选账目，一次修改分类、账户或标签，整理一个月只要几分钟。

还有这些细节。

深色模式

全局搜索

按金额、备注、商家或日期，瞬间找到任何一笔。

照片附件
