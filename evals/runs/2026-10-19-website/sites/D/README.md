# 青柠记账 Lime Ledger · 官网

虚构的 iPhone / Mac 记账应用「青柠记账」的完整静态官网。纯 HTML / CSS / JS，没有构建步骤、没有外部 CDN 和网络字体，整个目录直接上传到任意静态托管即可上线。

- 本地预览：在本目录运行 `python3 -m http.server 9104`，打开 <http://127.0.0.1:9104/>。
- 部署：上传整个目录（不含本 README 也可以）。站点需部署在**域名根路径**，见下文「404 页面」。

---

## 1. 页面结构

```
index.html                    首页：主视觉 + 两台 iPhone 界面、要点数字、功能便当格、Mac 版、隐私、价格摘要、最新博客、下载

faq.html                      常见问题：4 个分类 17 个问题，可搜索、可深链（如 faq.html#refund），无结果时有空状态
blog/index.html               博客列表：置顶文章 + 文章卡片
blog/lime-ledger-3.html       文章：青柠记账 3.0 发布说明
blog/three-accounts.html      文章：三个账户就够了（含表格、引用、提示框）
blog/budget-that-sticks.html  文章：预算不是节食
blog/feed.xml                 Atom 订阅源
about.html                    关于我们：起源、三条原则、时间线、团队
contact.html                  联系我们：带校验的留言表单（无后端，模拟发送并显示成功状态）+ 其他联系方式
```

每个页面都是完整、独立的 HTML：页头、页脚和图标精灵直接写在每页里，不依赖 JS 注入，所以没有 JS 时内容和导航同样可用。**修改页头或页脚时需要同步修改全部 12 个页面。**

## 2. 主要设计决策

按 Apple-Style 技能的流程，先分别判定了四件事（`cheatsheets/rules-and-evidence.md`）：

| 维度 | 判定 | 结果 |
|---|---|---|
| 目标平台 | 跨平台 Web（访客可能用任何设备） | 不按视口宽度推断平台，不模拟原生窗口 |
| 应用类型 | 内容型营销网站 | 保留网页式导航；不加侧边栏、检查器或 `.as-window` |
| 输入方式 | 触摸 + 指针 + 键盘 + 读屏 | 用 `any-pointer: coarse` 判定手指，触摸目标 44px；键盘全程可用 |
| 可用容器 | 320–1920px | 1024 以上桌面布局，900 以下折叠为菜单；正文限制在可读宽度 |

**材质分层（HIG Materials）。** Liquid Glass 只用于浮动的导航与控件层：顶部导航链接组（regular glass，组内项共用一个玻璃背景）、唯一的主操作「免费下载」（prominent glass，只染这一个）、移动端菜单（large glass）。内容层（卡片、列表、表格）全部是实色或标准背景，没有玻璃叠玻璃。导航下方用库的 **scroll edge effect** 代替栏背景和分隔线。运行时会在导航经过深色区域时把玻璃切换为深色（已实测）。移动菜单关闭了折射（`data-lens="off"`）并加厚填充，因为它承载的是成段文字，可读性优先。

**颜色。** 品牌色只用在主操作、链接和选中状态，其余是系统语义色。青柠绿的文字/填充色都实测过对比度：浅色强调色 `#367512`（白底 5.66:1，`#f2f2f7` 底 5.07:1），深色强调色 `#a8e063`（所有深色表面 ≥ 8.9:1），白字按钮底色 5.66:1 / 5.09:1。眉题和说明文字用次级标签色而不是品牌色，避免「可点」与「不可点」同色（HIG Color）。表单输入框用 `#86868b` / `#6e6e73` 边框，满足非文本 3:1（WCAG 1.4.11）——库默认的填充式输入框不满足这一点，这里是有意覆盖。

**字体。** 只用系统字体：拉丁字母走 SF / Segoe UI，中文依次回退到 PingFang SC、Microsoft YaHei、Noto Sans CJK SC。按技能建议对中文去掉库里为拉丁文设计的负字距；标题启用 `palt` 让句末「，」「。」不留一整格空白，并用 `text-wrap: balance`；正文行高 1.65–1.85；文章中的强调用中文着重号（`text-emphasis`）而不是伪斜体；金额统一等宽数字。

**形状与布局。** 卡片圆角 28–32px，内部元素按同心原则取更小圆角（手机插图的屏幕圆角 = 外框圆角 − 边框宽度）。主要按钮是胶囊形。整页内容宽度 1120 → 1240 → 1360px 随屏幕放大，区块背景通栏铺满，所以 1920px 下不会出现两侧空白的「死边」；只有连续正文（文章、隐私政策）限制在约 680–720px 的可读宽度。

**产品插图。** 网站没有任何位图截图：iPhone 账单页、报表页、Mac 窗口、键盘、预算环、图表等都用 HTML/CSS/内联 SVG 绘制，尺寸以 em 为单位随容器缩放（Mac 窗口用容器查询，窄屏时像真正的窄 Mac 窗口一样收起侧栏）。好处是零图片请求、跟随深浅色、文字清晰。插图整体带 `role="img"` 和描述性 `aria-label`，内部装饰元素对读屏隐藏。插图里的数字彼此一致（如 6,000 预算 − 4,286.40 支出 = 1,713.60，分类金额合计等于总支出）。

**图标。** 按技能要求不使用 SF Symbols，全部为自绘 24×24、1.8 线宽、圆角端点的线性图标（内联 SVG 精灵）。没有绘制 Apple 标志或官方 App Store 徽章，下载按钮用文字。页脚注明了 Apple 商标归属。

**深浅色。** 所有颜色都是 `light-dark()` 令牌，跟随系统；页脚提供「自动 / 浅色 / 深色」切换（库的分段控件，`radiogroup` 语义，支持方向键）。选择保存在 `localStorage`，由 `<head>` 内联脚本在首次绘制前应用，不会闪烁；同时同步 `theme-color`。首页的隐私区块固定使用深色外观（`color-scheme: dark`），作为节奏上的对比。

**交互与动效。** 滚动渐显只用透明度和位移，时长 0.7s；开启「减弱动态效果」或打印时完全不隐藏内容。FAQ 用原生 `<details>`，展开动画是渐进增强。价格切换、外观切换是库的分段控件（运行时提供拖动、键盘和 `change` 事件，页面只监听 `change`）。表单按 `web-implementation.md` 的约定：真实 `<label>`、`autocomplete` / `inputmode`、失焦和提交时校验、错误文字紧邻字段并用 `aria-describedby` 关联、提交失败时聚焦第一个错误字段；成功后显示可聚焦的结果面板，toast（`role="status"`）只是补充确认，不是唯一反馈。

**404 页面。** 静态托管会在任意缺失路径（如 `/blog/a/b`）返回 `404.html`，因此它的资源和链接使用根路径（`/assets/...`）；其他页面全部用相对路径，可部署在任意目录甚至本地打开。若必须部署在子目录，请把 `404.html` 里的 `/` 前缀改成该子目录。

**上线前需要替换的占位内容。** 应用和团队是虚构的：

- 域名 `limeledger.example`（canonical、Open Graph、sitemap、feed、robots、邮箱地址）——全局替换即可；
- App Store 链接目前指向 `https://apps.apple.com/`（`index.html`、`pricing.html`）；
- 联系表单没有后端：`assets/js/site.js` 中「simulate the round trip」处换成真实请求即可；
- 如在中国大陆托管，需要在页脚加入 ICP 备案号（未虚构该编号）。

### 检查中发现并已修复的问题

- **跳转链接无法用键盘到达**：最初用 `visibility: hidden` 隐藏，导致它被移出 Tab 顺序。改为仅用位移移到屏幕外。
- **分段控件触摸目标不足**：库的分段控件每段 32px 高，触屏下改为 44px；小号按钮同理。
- **移动菜单背后内容未被模糊**：在无头 Chromium 中，整页环境下 40–48px 的背景模糊没有生效（单独测试时生效，可能与软件合成有关，未能在真机确认）。菜单改用 24px 模糊 + 88% 不透明填充，可读性不再依赖模糊半径。
- **打印时部分内容透明**：切换到打印媒体时渐显动画停在中间状态；打印样式中关闭了过渡。
- **数据前后矛盾**：Mac 插图写「比九月少 6%」，功能页写「比九月多 4%」，柱状图高度也对不上；已统一为多 4%。首页曾把「CSV 导出」列为 Pro 功能，与价格页（免费）矛盾，已更正。
- **强制颜色下卡片无边界**、**部分插图标签对比度不足**、**功能页内层卡片与背景同色** 等细节问题。

## 4. 维护说明

- `apple-style.css`、`liquid-glass.js`、`liquid-glass.mjs` 与 Apple-Style 技能中的版本逐字节一致，升级时直接替换；本站的覆盖全部在 `site.css` 顶部的令牌区。
- 新增页面时，复制一个现有页面，修改 `<title>`、`description`、`canonical`、导航中的 `aria-current`，并加入 `sitemap.xml`。
- 新增图标：在页面顶部的 `<svg class="sprite">` 里加一个 24×24 的 `<symbol>`，用 `<svg class="icon"><use href="#i-名称"/></svg>` 引用。
